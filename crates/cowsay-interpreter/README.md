# Cowsay Interpreter

A Rust implementation of a subset of the Perl5 interpreter.

Cowfiles use Perl5 scripts to create the `cow`. This interpreter aims to parse
all cowfiles in the [Cowsay GitHub organisation](https://github.com/cowsay-org).

## Implemented

### Keywords

- [ ] unless
- [ ] ne

### Standard library

- [ ] chop

### Tokens

- [ ] `=`
- [ ] `+`
- [ ] `-`
- [ ] `x`
- [ ] `.=`
